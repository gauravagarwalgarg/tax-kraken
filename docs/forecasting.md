# Forecasting And Estimates

## Forecasting

The three-year look-ahead uses a blend of:

- Linear trend over the historical series.
- Recent moving delta from the latest years.

This is intentionally simple and transparent. It should be treated as planning guidance, not as a filing number.

## Tax-Saving Estimate

The tax-saving estimate uses simplified Indian slab logic and compares estimated tax before and after deductions. It is useful for direction, but not a substitute for a tax computation utility.

## Net-Worth Proxy

The net-worth estimate is an income-capacity proxy. It is not a balance-sheet net worth calculation.

Actual net worth requires assets and liabilities such as:

- Bank balances
- Demat holdings
- Mutual funds
- Real estate
- Gold
- Loans and liabilities
- Insurance surrender values
